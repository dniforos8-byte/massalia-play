# Massalia — a city on the edge of the world

**▶ Play: https://dniforos8-byte.github.io/massalia-play/**

A punishing, hours-long historical survival city-builder, in an isometric Mediterranean world.
The start screen offers two cities, each with its own save:

- **Massalia** — the real Marseille, from its founding by Phocaean Greeks in 600 BC to 0 AD.
- **Syrakousai** — Syracuse, on Sicily, from 734 BC to 190 BC.

Runs entirely in the browser — one file, no install, no account, nothing to download.
Best on a desktop browser. Use **Save & quit** to keep a city between sittings; the game also
saves itself each time an event is answered, in case the tab closes.

This is the one playtest link. The two-city preview that used to live at
`dniforos8-byte.github.io/massalia-two-cities` now forwards here, and any save made there is
already here: to a browser, both addresses are the same site.

This repository holds only the compiled build for sharing. It is published from a private
source repository and is not the place to read or contribute to the code.
