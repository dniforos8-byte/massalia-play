# Massalia — a city from 600 BC

**▶ Play: https://dniforos8-byte.github.io/massalia-play/**

A punishing, hours-long historical survival city-builder. Nurse the real Marseille from its
600 BC founding by Phocaean Greeks toward greatness, in an isometric Mediterranean world.

Runs entirely in the browser — one file, no install, no account, nothing to download.
Best on a desktop browser. There is no autosave: use **Save & quit**.

This repository holds only the compiled build for sharing. It is published from a private
source repository and is not the place to read or contribute to the code.
